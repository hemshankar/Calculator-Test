# Digital Calculator

A small web-based digital calculator (HTML/CSS/JS).

Features
- Basic arithmetic: add, subtract, multiply, divide, modulo
- Decimal support
- Clear and delete (backspace)
- Keyboard support (digits, ., + - * / %, Enter, Backspace, Delete/Escape)
- Responsive layout for mobile and desktop

Files
- `index.html` — UI (already added)
- `styles.css` — styles & responsive layout
- `script.js` — calculator behavior and keyboard handling

How to run locally
1. Clone the repository
2. Open `index.html` in your browser (no server required)
